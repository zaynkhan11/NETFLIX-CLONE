# Netflix Clone

A Netflix-inspired frontend clone built with HTML and CSS.

## Technologies
- HTML5
- CSS3
- SVG / WebP assets

## Project Structure
- `index.html` — main webpage
- `style.css` — styling
- `Assets/` — images, fonts, icons, and videos

## How to Run
Open `index.html` in a web browser.

## Note
This is a frontend practice/portfolio project and is not affiliated with Netflix.
